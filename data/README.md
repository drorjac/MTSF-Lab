# Data Links for BSTN-MTS-Forecast

This document contains links to the datasets used in the project. Below is a list of the datasets with their descriptions and access instructions.

## Dataset: Wireless Link Measurements (2015-2017)
- **Description**: Our dataset contains wireless links measurements between the years 2015 to 2017 from various locations in Sweden. It is instrumental in understanding the impact of weather conditions on wireless network performance.
- **Source**: Data is provided by Ericsson AB. For access and more detailed information, please contact the organization directly.
- **Usage**: Analyzing and forecasting weather-induced attenuation in wireless networks.
- **License**: Please refer to the provider for license details.

## OpenMRG Dataset (June-August 2015)
- **Sources**: 
  - For full description, refer to the following article: [OpenMRG: Open data from Microwave links, Radar, and Gauges for rainfall quantification in Gothenburg, Sweden](https://essd.copernicus.org/articles/14/5411/2022/essd-14-5411-2022-discussion.html).
  - Download Zip File:  [OpenMRG Dataset on Zenodo](https://zenodo.org/records/7107689)
- **Description**: OpenMRG consists of data from 364 bi-directional commercial microwave links (CML), a C-band radar composite, and 11 rainfall gauges covering Gothenburg, Sweden during June-August 2015. The CML data, with 10s resolution and true coordinates, offers an extensive view of network behavior under various weather conditions.
- **Usage**: This dataset is designed for comprehensive training and evaluation of the BSTN model in time series forecasting. It supports detailed temporal analysis and modeling. Moreover, the dataset includes additional weather data like rainfall measurements from rain gauges and radar, making it highly suitable for studying weather effects on wireless networks.
